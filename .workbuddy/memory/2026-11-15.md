### 2D MV 的结论
- `LiveSettingData.LiveModeType` 五档，`Mode2D = 2` 才是 2D MV。
- `Background2DView` 有 `movieModeRoot`（MV）/ `jacketModeRoot`（封面）两个子模式，
  各配一台相机 —— **没有 2D MV 的歌会退回封面，不是靠猜**。
- 播放器是 **CriWare Sofdec2（CriMana）**，不是 Unity VideoPlayer；
  `MovieManager` 按 key 管最多 3 路，usm 从 bundle 解到本地缓存再播。
- `MusicVideo2DModeData`（bundle `live_pv/mv_data/{id}`）= `movieName` + seek 帧表，
  一首 MV 可以是多段 usm 拼接。
- **时间同步 asm 实证**（VA `0x50ACC08`）：`frame = trunc(framerateN/1000 × ms/1000)`，
  `framerateN` 是**千分单位**（60000=60fps），截断不是四舍五入，clamp 到末帧，`<1` 不播。
- 我们只有 `StageBackground`（封面投舞台屏）= 原作 `jacketModeRoot`，**零视频通路**。
  要做得补 ffmpeg 解码 + GL 外部纹理 quad + 音频主钟。

### 分数公式的结论
- `ScoreLogic.CalculateAddScore`（VA `0x545E5B8`）：四因子连乘
  `基础分 × 音符系数 × 判定系数 × 连击系数 [× dropOutFactor]`。
- 音符系数是 master `ingameNotes` 15 行表（已下载 `build/ingameNotes.json`）：
  normal/long/flick=10、critical=20/30、long_mid/friction=1~2。
  **和我们的 `hudWeight()` 是 10:1 关系，比例全对**。
- `levelFactor = 1 + (playLevel-5) × 0.005`（VA `0x545CC44`，常量池 `0x1F242F0` = 0.005），
  和我们现有实现一字不差。
- **连击系数原作是阈值查表**（`List<KVP<int,float>>` + 二分），我们硬编码「每 100 连 +1% 封顶 1.1」
  —— 这条不一样，但表内容没取到（要真机 dump）。
- 扣血 50/80 与 40/40 全对上。
- `playLevelScore`（S/A/B/C 线）公开镜像**没有**（diff repo / unipjsk / sekai.best 全 404），
  只能从 prefab 刻度反推。

### 分数：综合力是硬证据
`ScoreLogic.Setup` VA `0x545CC08`-`0x545CC74`：
`[bootData+0x28]=DeckData` → `[DeckData+0x28]=TotalPowerIncludeBuff` → `lsl #2`（×4）
→ `× levelFactor` → 除以 Σ权重 → `BaseNoteScore[0xC0]`。
**所以分数与综合力线性相关**；我们 `kTeamPower=250000` 写死，等价于恒定 25 万综合力。

### 等级线与综合力无关
`playLevelScores` 7 种 liveType × 40 级：
- `S = 1040000 × levelFactor`、`A = 840000 ×`、`B = 400000 ×`（与 liveType 无关）
- `C` 三档：challenge 4000 / solo·rank_match 20000 / multi·CC·tournament 40000（同样 ×levelFactor）
- 7 种 liveType：solo / multi_open / cheerful_carnival_open|private / rank_match /
  preliminary_tournament / challenge_live

### 判定 / 连击系数（纠正上一轮）
- `ingameNoteJudges` 7 行：perfect 1.0 / great 0.7 / good 0.5 / bad 0 / miss 0 /
  **dead 0.7 / auto 0.7**（我们 auto 给 1.0，是有意的）。
  注意该表 `damage`（miss=100）与 `ingameNotes.damageMiss`（80）不一致，
  实际扣血走后者。
- `ingameCombos` 11 行：每 100 连 +1%，1001+ 封顶 1.1 → **和我们的实现完全等价**，

### ffmpeg
- **本机 ffmpeg 直接认 usm**：`-i` 输出 `usm / mpeg1video 576x328 24fps`，
  只有视频流无音频。→ 2D MV 解码链路很窄。
- 体积：全量静态 102MB；裁剪（只留 usm+mpeg1）估 4~8MB；自制 usm 解析只链 avcodec 估 3~5MB。
