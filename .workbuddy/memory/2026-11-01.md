**徽章（FULL COMBO / ALL PERFECT）的精确坐标**（anchor 全是 0.5/0.5，直接累加）：

```
AnimationRoot(0,0) → ScoreDetail(-335,-208) → ComboDetail(198.8,150.1)
    ├ FullCombo   (44.2, 35.1)   size 600×120   → 相对屏幕中心 (-92.0, -22.8)
    └ AllPerfect  (177.6, 35.1)  size 600×120   → 相对屏幕中心 (41.4, -22.8)
    子 image/Image 都 (0,0) size 256×26
```

**⚠ 不能直接替换 `kBadgeCenterX/Y`（现在 1490/656）**：项目的结算页是照参考截图摆的
**绝对像素坐标**，Unity 那套是相对屏幕中心的单位，两套坐标没有直接映射。要换算得先找
一个"两边都已知"的锚点（比如 COMBO 数字）做仿射变换。**这是个独立的校准任务，别看着
数字就改**。

另外：`image` 是 **256×26**，和 `badge_result_fullcombo` 的 358×76 比例（4.7:1 vs 9.8:1）
对不上 —— 那个子节点用的可能不是这两张徽章，得导 YAML 看 `m_Sprite` 才能确定。
