### 踩过的坑（下次别再踩）

1. **`arip_search` 的 `/Assets/Yaml` 只收组件**，GO 要 `/Assets/View`；而且
   `ms_geom.py` 只给 rect，**要组件字段得逐节点拉** → 为此新写了 `arip_dump.py`
   （导出每个 GO 的 Image/Text/Layout/Shadow YAML，`--all` 保原始 YAML）。
2. **`ms_geom.py` 的 `parent` 靠 `m_Father` 反查会整棵树断掉**（这批 prefab 的
   transform 父子关系只在 `m_Children` 里可信）→ 树要用 `m_Children` 走。
3. **浮点常量别手算**：`mov w8, #-0x3d700000` 反汇编显示看着像 -3.65，
   按位解出来是 `0xC2900000 = **-72.0f**`。同理 `SIZE_DIC` 的 Small 是 **336** 不是 567。
   **一律 `struct.unpack('<f', struct.pack('<I', imm16<<hw))` 复核。**
4. **跨函数找静态字段初始化点很难**：`adrp+ldr` 的 xref 扫描要按 **scale=8**（`ldr x`）
   算目标，我一开始按 ×4 算，扫出 0 个引用。写正确后能定位到 2 个引用。
5. **`dump/script.json` 的 `Addresses` / `ScriptMetadata` 覆盖不到 .data 里的类槽位**
   （区间是 metadata/file 地址，不是 klass 指针），所以「`0xB6F7908` 这个槽属于哪个类」
   查不到名字。结论「起始缩放=0」是由关闭动画的 `fmov s0, wzr` 对称性 + 目标值 1 反推的，
   文档里已标成推断。

## 教训：接线 UI 时**不要照印象画**

用户直接指出了：「你又乱写，这一点都不像，几何、配色什么的都是你自己编的」。

第一版多人结算的成员卡，我画了圆盘头像 + 玩家名字首字、七种「座位色」、
两列六格判定计数、底部 FULL COMBO 字。**这些在原作里一个都没有**：
- 原作卡上**没有判定计数**（那在 score 页）；
- 原作卡是 **#EBEBF2 + 圆角 48** 的浅色面板，不是深色；
- 没有「座位色」这种概念，只有一条 **#FF5577 的指名色条**（64.1×19.72）；
- 徽章在**卡上部** c(y+44)，不是我放的底部。

**根因**：ms_geom.py 只给 m_AnchoredPosition，脱离 anchor/pivot 全是 0 或没法解释，
我于是「看起来像那么回事」地补全了。正确做法是解矩形。

### 新增工具 
ect_resolve.py（D:\Tools\rea\work\jp\）

按 Unity 的规则解绝对矩形：
`
anchorRect = parentMin + anchor*parentSize ... parentMin + anchorMax*parentSize
pivotAbs   = lerp(anchorRect.min, anchorRect.max, pivot) + anchoredPos
size       = (anchorMax-anchorMin)*parentSize + sizeDelta
rect       = pivotAbs - pivot*size
`
用法 python rect_resolve.py <prefabId> [--yaml]。

**两个坑**：
1. m_Children 里放的是 **RectTransform 的 PathID**，不是 GameObject 的 →
   要用 .go(go) 里 Class ID Type Name == "RectTransform" 那一行的 pid 当 key，
   否则整棵树一个父子关系都连不上。
2. **m_Father 和 m_Children 的 {m_FileID, m_PathID, m_TargetClassID: 4} 长得一模一样**，
   全 YAML 正则会把父节点当成子节点 → 形成环 → 
oots 为 0（我第一次就踩了）。
   只扫 m_Children: 那一段。

### 结论

**能画什么必须由 prefab 决定**：矩形、m_Color、m_fontSize、spriteName。
没有的数据（卡面图、卡等级、称号、卡框）就**空着**，并在文档里写明为什么空着 ——
不要找「差不多」的替身。替身比空白更糟，因为它看起来像真的。
