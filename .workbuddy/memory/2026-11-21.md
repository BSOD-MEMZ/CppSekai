### 踩过的坑（下次别再踩）

1. **`arip_search` 的 `/Assets/Yaml` 只收组件**，GO 要 `/Assets/View`；而且
   `ms_geom.py` 只给 rect，**要组件字段得逐节点拉** → 为此新写了 `arip_dump.py`
   （导出每个 GO 的 Image/Text/Layout/Shadow YAML，`--all` 保原始 YAML）。
2. **`ms_geom.py` 的 `parent` 靠 `m_Father` 反查会整棵树断掉**（这批 prefab 的
   transform 父子关系只在 `m_Children` 里可信）→ 树要用 `m_Children` 走。
3. **浮点常量别手算**：`mov w8, #-0x3d700000` 反汇编显示看着像 -3.65，
   按位解出来是 `0xC2900000 = **-72.0f**`。同理 `SIZE_DIC` 的 Small 是 **336** 不是 567。
   **一律 `struct.unpack('<f', struct.pack('<I', imm16<<hw))` 复核。**
4. **跨函数找静态字段初始化点很难**：`adrp+ldr` 的 xref 扫描要按 **scale=8**（`ldr x`）
   算目标，我一开始按 ×4 算，扫出 0 个引用。写正确后能定位到 2 个引用。
5. **`dump/script.json` 的 `Addresses` / `ScriptMetadata` 覆盖不到 .data 里的类槽位**
   （区间是 metadata/file 地址，不是 klass 指针），所以「`0xB6F7908` 这个槽属于哪个类」
   查不到名字。结论「起始缩放=0」是由关闭动画的 `fmov s0, wzr` 对称性 + 目标值 1 反推的，
   文档里已标成推断。
