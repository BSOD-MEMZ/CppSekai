# 2026-10-21

## 抓取 + 分析 pjsk.moe 的剧情播放器

用户觉得 <https://pjsk.moe/zh-cn/story/unit/3/mmj_01_00/> 的 Live2D 演出比我们的剧情层好，
要求整站拉下来分析。落盘在 `build/ref-pjskmoe/`（build/ 已 gitignore），报告 `ANALYSIS.md`。

### 结论（下次接着干时直接看这几条）
- 播放器**不是网站自己写的**：`sse-web 1.0.0-06fb77fbc8dc`，SekaiStoryExporter(Rust)→wasm，
  五个执行体：page / sim-worker(Pass1+混音) / render-worker(Pass2,**WebGPU**) /
  audio-worklet(**音频当全局时钟**) / kit-worker(从客户端解包派生 UI 套件)。
  开播前把这一话全部资源预载完，播放中零网络。
- 站点壳是 Next.js 16 + MD3，源码开源：`StarMoe-org/Moesekai`（AGPL-3.0），
  文档在 `web/docs/story-live2d-player.md`、`story-player.md`（写得很细，值得再读）。
- 真正"好看"的原因不是代码，是**素材是原件**：
  - 对话框 = `bg_story_adv.png` **4×399** 九宫格（border L2），名牌/按钮同理；
    参数在 `_objects/resources.assets/Sprite.json` 的 `tree.m_Border`(x=L,y=B,z=R,w=T)。
  - 背景是游戏 2–3MB WebP，语音/BGM 是 ACB 解出的原件，字体是 FOT-Rodin（商业，别分发）。
- 剧本是**官方 scenario JSON**：`Snippets`(Action→分表) + `TalkData`/`LayoutData`/
  `SpecialEffectData`/`SoundData`，`Delay` 秒、`ProgressBehavior` 0=等 1=立刻继续。
  Action 1=Talk 2/4=Layout(Type 0 对 4、Type 1/2/3 对 2，按条数吻合推断) 6=Effect 7=Sound。
- Live2D：`library/live2d/model/<costume>/` 是**标准 Cubism 3**（moc3+physics3+model3+2048 贴图），
  官方 Native SDK 能直读；但动作是自家的 `*.sse-motion.json`，不是 motion3.json。
- 资源 URL 规则（记下来省得再猜）：
  `<lib>/ripper/<jp|cn|tw|kr|en>/ripper.lock.json`
  `<lib>/ripper/<region>/episodes/<kind>/<group>/<n>.json`（一话资产清单）
  `<lib>/ripper/<region>/library/live2d/{model,motion}/...`
  `<inapp>/<region>-<ver>/player/data.unity3d/{Sprite,Texture2D,Font,_objects}/...`
  剧本/背景/语音在 `storage.exmeaning.com/sekai-<region>-assets/scenario|sound/...`
  masterdata 在 `metadata.exmeaning.com/<region>/master/*.json`
  `<lib>` = `https://assets.pjsk.moe/sekai-extra-assets/sekai-story/ripper/`
- 规模：日服 7679 话；单话实测 **147MB**（模型 16M + 背景 20M + 语音 43M + 字体 32M + 影片 17M）。

### 工具经验
- 抓 Worker 内的请求必须 `Target.setAutoAttach{flatten:true}` 再对 sessionId 发 `Network.enable`，
  否则只能看到 page target 的请求（拿不到 wasm/模型/贴图）。
- 无头/正常 Edge + CDP 脚本：`build/ref-pjskmoe/cdp2.mjs`（可复用），
  点按钮用 `[...document.querySelectorAll('button')].find(b=>b.textContent.trim()==='加载并播放')`。
- 详见 memory 里的 url 镜像脚本 `grab.py`（带 `?query` 的文件名要替换，Windows 不允许 `?`）。
