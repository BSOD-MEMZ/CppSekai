# 2026-10-11

## 设置界面层级重排（A+B+C）

用户反馈「设置界面层级关系很不明显、很杂乱」，要仿 pjsk 官方设置界面。
看官方截图抓到的关键点：**分组标题是「灰色胶囊通栏条 + 居中深灰文字」**（演出音量 / 系统音量 /
音符设置），而且官方**几乎不写解释小字**，全靠分组标题 + 控件本身说话。

### 新增组件
- `ui::sectionLabel(text, rowWidth, topGapPx)`（game/Ui.hpp / Ui.cpp + `kSectionBg`）：
  灰底胶囊通栏标题，高 23*s、条上间距 5*s、条下留 5*s。设置卡片各页用它分组。
- 按键映射**独立卡片**（main.cpp `drawKeymapCard`，520x440）：演奏页只留一行
  「按键映射　<当前键位摘要>」，点开是 3 列 × 4 行网格 + 恢复默认 + 关闭。
  新增 `keymapCardOpen` / `keymapCardAlive`；**补进 `escapePressed` 链**
  （不补的话卡片开着按 ESC 会一路落到 else、把游戏关掉）；`CPSEKAI_KEYMAP=1` 无头打开。

### 页签重排：6 → 7 页
演奏 / **画面** / **外观** / 判定 / 系统 / 账户 / 关于。
画面页原来 16 项、超 view 346px，拆出「外观」后两页都放得下。
卡片 380 → **440** 宽（七个两字页签在 380 下会互相压）。

### 归类搬动
- 手柄震动 + 震动×3 → 跟「按键映射」同一组（新的「输入与外设」）。
- 开始游戏时切到英文输入法：演奏 → 系统 > 系统集成（本质是跟 Windows IME 打交道）。
- 显示帧率：外观区 → 画面 > 性能。
- 删掉的说明 label：演出能量下面那行倍率说明（并进标题「演出能量（经验 ×120）」）、
  「把 刷新谱面列表…只在 windowed 显示」、「双击 .sus…还回去」、
  「多人游玩需要允许多开 / 先开的窗口是房主」（只留「已开启，重开生效」）、
  账户页「只存在本机 userdata.json…」。

只剩「判定」页超出（它一直是有意滚动的：8 个滑杆 + 2 个预设行 + 2 个开关），其余六页不滚。

### 坑
- 改 `--settings-tab` 范围要**同步四**处：help 文本、CLI.md、AGENTS.md、
  `std::clamp(std::atoi(...), 0, 6)`。
- 删「数据只存在本机 userdata.json。」那行时**误把下一行 `const double need = ...` 一起删了**，
  编译才炸出来 —— 改完必须 build。

  连跑多个 tab 时日志会被覆盖，**一次跑一个 tab** 才能留住对应数值。
