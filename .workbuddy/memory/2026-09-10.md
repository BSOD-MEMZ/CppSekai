## 选曲界面改版 + 输入法 + HUD 真数据 + hold 尾判 + 卡死修复
- **选曲列表**（`game/SongSelect.cpp`）：紧凑行去掉整块深色底，改为悬停高亮 + 底部半透明白分隔线
  （`IM_COL32(255,255,255,48)`）；选中行改为半透明白圆角矩形（alpha 190）+ 白描边；
  左侧定数指示的填充色不再是固定红，改用 `diffColor`（跟随当前选中难度）。
- **指示图修正**：之前误用 `indicate_back.png`。实际是 `select/` 里 5 张 `indicate_back_new.png`
  并排（38x38，不做 UV 切分），其上再叠 `clear` / `fullcombo` 指示（同尺寸直接叠，FC 优先于 clear）。
  未 present 的难度用 alpha 84 压暗。
- **右侧手机倾斜**：`kTiltDeg = -5.0f`，用 `tiltPoint`/`tiltedItemPos` 算旋转后坐标，绘制时记录
  `phoneVtxFirst = dl->VtxBuffer.Size`，块末尾统一旋转该段 ImGui 顶点；命中框不能旋转，所以
  `InvisibleButton` 放到旋转后的中心。确定按钮从 `ui::capsuleButton` 改手绘圆角矩形跟随倾斜。
- **输入法遮挡**：`SDL_HINT_IME_SHOW_UI` 默认 "0"，而 ImGui SDL2 后端是在 `SDL_CreateWindow`
  **之后**才设这个 hint，对主窗口不生效。必须在建窗前自己设 "1"（另加
  `SDL_HINT_IME_INTERNAL_EDITING="0"`）。位置：`main.cpp` SDL_Init 之后、建窗之前。
- **HUD 真分数/血量**：从 `D:\Dev\mmw-preview-web` 的 `native/src/mmw_overlay_player.cpp` 移植成功。
  评分 `delta = (TEAM_POWER/weightedCount) * 4.0 * weight * levelFactor * comboFactor`，
  TEAM_POWER=250000、RATING 默认 26、comboFactor 每 100 连 +0.01 上限 1.1、判定系数 P1.0/G0.7/G0.5；
  `hudWeight()` 给每类事件权重（tap 1/2、flick 1/3、trace 0.1/0.2、hold tick 0.1/0.2、marker 0）。
  `scoreRankAndBar()` 段位阈值随定数走，分数条比例用 `state.scoreBarRatio`（**原来错用了 lifeRatio**）。
  血量官方表：初始 1000、MISS -80、长条中途断 -40，`clamp(0,1000)`。
- **hold 尾判**：谱面核心在长条结束时刻会**额外发一个普通 tap/flick/trace 事件**（SUS `HoldEnd`），
  在 HitEvent 流里无法直接区分 → 在 `Judgement::load()` 里用「同时间(±20ms)同轨道对上 kind 5
  标记的 endTimeSec」给它打 `holdTail` 标记，`findCandidate` 跳过这些尾事件。
  判定规则：结束前 ≤perfect/great/good 松手给对应等级；一直按到底也算 Perfect；提前松手且超过
  `kHoldStartGraceSec=0.14s` / 距尾 > `kHoldGraceSec=0.18s` 才算断连(-40)。
  坑：`ActiveHold::startIndex` 初值必须是 `-1` 哨兵（原来 0 会误判成 index 0 的 note），找不到
  sibling 起点时退化为 `startIndex = i`；起点用三态（0 未定/1 命中/2 miss）而不是布尔 engaged。
- **卡死严重 bug（放弃后重选曲）**：根因是 miniaudio 的 `ma_sound_init_from_file` 内部会
  `MA_ZERO_OBJECT(pSound)`，对**已初始化**的 ma_sound 再 init 会丢掉引擎资源表里的节点，
  之后引擎遍历到坏节点直接挂死。修复：`AudioEngine::loadMusic()` 开头若 `mMusicLoaded` 则先
  `ma_sound_stop` + `ma_sound_uninit` 再重新 init。
- **新增无头回归用例**：`--test-restart` / `--restart-at <sec>`（走到指定秒数执行「放弃→载入下一首」
  再正常退出）。验证方式：把修复改成 `if (false && mMusicLoaded)` 能复现旧 hang（55s 进程仍存活），
  恢复后正常 ~12s 截图退出。截图前统一打印
  `[stats] perfect=.. great=.. good=.. miss=.. combo=.. maxCombo=.. tails=.. breaks=.. score=.. life=.. (..%)`。
  基线：`--test-hits` 全谱自动打 → `perfect=283 miss=0 tails=8 breaks=0 score=279556 life=1000 (100.0%)`；
  无输入 → `breaks=0`（未开始的长条整条只算 1 个 MISS）。
- 本文件顶部那条「`hudState.lifeRatio` 硬编码 1.0」已作废，now 接的是 `judgement.lifeRatio()`。
