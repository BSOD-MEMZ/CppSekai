
## 2D MV：intro 结束后硬切视频（去掉从紫底板渐变）
- 现象：带 MV 打歌，intro 卡消失后先看到紫色舞台底板，1.8s 才渐变成 MV。
- 根因：`main.cpp` 把 `renderer.setBackgroundVideoMix(visibility)` 直接绑在
  `openingPlayfieldVisibility`（上游 1.8s 淡入曲线）上 → 视频 alpha 从 0 爬到 1，
  底板一直是底。原作 Mode2D 是硬切。
- 修：mix 改 0/1 二值（intro 期间 0，卡片一结束 1）；stage quad 仍走 visibility（前景）。
  两个防退化：`mvShownFrame>=0`（有解出帧）+ `mvFrameCaughtUp`（**粘性**追上标记，
  不能用实时 lag —— MV 比谱面短时播完帧号停住，歌尾会退回底板）。
- 新增诊断日志：`--screenshot` 打 `[mv] shot frame=N lag=M`，用来区分「MV 这帧本身黑」
  和「纹理没帧」。0087 实测：t=-1 帧 193 本身就是黑的（usm 内容），t=10/115 正常，
  稳态像素与旧版一致（119,132,135 vs 119,132,136）。
- 文档：MV2D-SCORE.md §1.8 更新成"已实现 + 硬切规则"。
