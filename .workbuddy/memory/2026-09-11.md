## 新增 CHARTS.md（给玩家的谱面下载指南）+ 清掉「flick 到底有没有校验」的矛盾
- 新文件 `CHARTS.md`（仓库根，和 SETUP.md 平级），README 第 2 节 / 第 9 节目录、SETUP.md 都加了链接。
  内容：一键 `setup.sh --charts`；目录与命名约定（`<id4>_<难度>.sus` / `<id4>.mp3` / `<id4>.png` /
  `<id4>.json` 全难度共用 sidecar / `music-levels.json`）；用 `musics.json` 查曲目 id；
  URL 模板；复制即用的下载脚本；sidecar 字段表（含 `fillerSec`/`offset`）；定数说明；F5 重扫；
  常见问题表。
- **实测过的 URL 规律（本次新确认，之前文档只写了 BGM 一条）**：
  - 谱面 `https://assets.unipjsk.com/startapp/music/music_score/<id4>_01/<难度>`，**末尾没有扩展名**，
    下完要自己改名成 `<id4>_<难度>.sus`；难度= easy/normal/hard/expert/master。
  - BGM 两个候选，依次试：`.../ondemand/music/long/se_<id4>_01/se_<id4>_01.mp3`（游戏短版，多数歌）
    和 `.../ondemand/music/long/<id4>_01/<id4>_01.mp3`（**原曲完整版，老歌只有这个**，
    实测 0001/0002 的 `se_` 版是 404 而 plain 版 206；0075 两个都有）。不是每首都有 BGM。
  - 曲绘 `https://assets.unipjsk.com/startapp/music/jacket/jacket_s_<id3>/jacket_s_<id3>.png`，
    **3 位补零**（`jacket_s_075`），而谱面/BGM 是 **4 位**——这是最容易踩的位数坑。
- **「flick 到底有没有校验」的真相**：`game/Judgement.cpp` 的 `findCandidate()` 里
  `mStrictFlick`（`Judgement.hpp`，**默认 true**，设置面板「严格 Flick 方向」复选框）已经实现了
  严格校验：点按永远清不掉 flick、滑动也永远清不掉 tap；up/default 与 legacy `FlickNone`
  接受「上滑或无方向」，left/right 必须给对方向。证据链：`core/native/src/mmw_preview.cpp`
  SUS `#xxx15` 通道（channel digit 5 = directional，type 1=Up/3=Left/4=Right）→ 核心写进
  HitEvent `flags` bits1-2（bit0 才是 critical）→ `Judgement` 的 `noteFlickDir()` 比对 →
  `main.cpp` `movePointer()` 按主轴速度给 `FlickUp/Left/Right`。
  **矛盾来源：文档过期。** `AGENTS.md` 待办第 1 条和 `README.md` 待办第 1 条（「生命值是假的，
  hudState.lifeRatio 硬编码 1.0」）都还在列已经做完的事。两处都已改成「已做完的旧待办」列表，
  并在 AGENTS.md「约定与坑」补了 flick 严格校验的完整说明（含 `flags` 位布局）。
- **顺带修的真空洞**：`game/SongSelect.cpp` 空列表提示写着「按 F5 刷新」，但 F5 从来没接过，
  且 `game::SelectRescan = -3` 定义了、`main.cpp` 里有处理分支，却**没有任何地方返回它** —— 整条
  重扫路径是死代码。已接上：`main.cpp` 事件循环加 `SDLK_F5 && state == AppState::Select` →
  `rescanRequested` 逐帧标志，在选曲块里和 `action == SelectRescan` 合并成 `wantRescan`
  （放在 `drawSongSelect()` 之后立刻消费，避免漏进后面的帧）；提示文案补了 CHARTS.md 指引。
  已验证：`bash build.sh` 通过，`--screenshot` 选曲界面无回归（`[select] 10 chart(s)`）。
- 提示：`build/` 里的 exe 上一级就是仓库根，所以谱面直接放仓库根 `charts/` 即可，
  不用手动拷进 `build/`（`chartCandidates` 的顺序是 `--charts` → `exe/charts` → `exe/../charts` → `./charts`）。
