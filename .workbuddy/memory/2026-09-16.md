### 谱面目录约定变了
- 下载器默认输出改成 **exe 同级 `charts\`**（原来是 `..\charts`）。
  起因：打包版解压出来是 `CppSekai-<日期>\`，`..\charts` 会落到游戏文件夹**外面**。
- 游戏侧跟着改成**多候选合并**（按 .sus 文件名去重、先到的目录赢），
  所以 `build\charts` 和仓库根 `charts` 同时可见，老库不会“消失”。
- `.gitignore` 加了 `profiles/` 和 `chartdl.json`。

### 多用户（初步）
- `profiles\<id>.json` 一人一份，`profiles\index.json` 记 active + 名单；
  首次运行把 `userdata.json` **复制**成 `default` 用户（复制不搬，回滚老版本照样跑）。
- 设置 → 账户 里新建/切换/删除（删除只从名单里拿掉，文件留着）。
- **最大的坑**：`persistUserData()` 的方向是「把 live 值抄进 userSettings 再写盘」，
  切换用户后不重推 live 镜像就会把上一个用户的窗口尺寸/帧率/速度写进新用户的档里
  （实测 default 被 second 的 800x450/144 覆盖）。已修：`activateProfile()` 里逐个重推。
- 账户页那三个 InputText 的 static buffer 也要按 `bufProfile` 重填，否则串名。
- 无头检查：`--activate-profile <id>`。

### 渲染模式
- `UserSettings::renderScale`：0=窗口多大渲染多大 / 1=固定分辨率（FBO + 等比黑边）。
- 三件必须同时成立：`windowW/H`=渲染尺寸、指针事件在进 switch 前改写坐标、
  `ImGui_ImplSDL2_NewFrame()` 之后设 `io.DisplaySize`=渲染尺寸 + `DisplayFramebufferScale`=1。
  这样游戏/ImGui/触摸三套代码**零改动**。
- 分辨率预设降到 640x360 + 「自定义」宽高（提交才 resize，`IsItemDeactivatedAfterEdit`）。
- 无头检查：`--render-size <w>x<h>`（配 `--width/--height` 造出窗口≠渲染尺寸）。

### 验证手法（这轮摸出来的）
- **当前模型看不了图**，所以全靠：日志断言 + Pillow 像素探针 + `winsend` 点击。
- `shot_probe.py` 加了 **Pillow 回退**（这台机器没有 ImageMagick），现在能用。
- `build/winsend.exe` 不在仓库里，要自己编：
  `zig cc -O2 .workbuddy/tools/winsend.c -o build/winsend.exe`。
  **它的 click 会先发 WM_MOUSEMOVE**（SDL 的按键事件用的是最后一次移动的位置），
  而且 `EnumWindows` 要求窗口可见——进程退了就找不到窗口。
- 坐标映射的正确性用一个**确定性的**目标验证：`--result-preview` + 点结算画面的「继续」
  （`resultContinueHitTest` 的矩形是写死的，能算出窗口像素），窗口模式与固定模式下
  **同一个窗口像素**都要命中，日志出现 `[result] continue -> song select`。
- 注意 `--result-preview` 会在结算出现后 ~2.6s 自动截图退出，点击要在那之前**连点**。

### 下载器
- 已下载状态：整首齐（该有的难度 + 曲绘 + sidecar，**演唱版本不算**）→ 行灰显+勾选被顶回；
  部分 → 右侧已存在项打勾禁用并标 `✓已下载`。日志 `[scan] N complete, M partial` 是断言点。
- 队列跑完自动清勾选 + 重扫 + 气泡（可选）。
- 设置窗口是独立顶层窗口（父窗口 EnableWindow(FALSE) 做模态），
  WM_CREATE 里必须 `AdjustWindowRectEx` 重算大小，不然底部按钮跑到标题栏外。
- 分割手柄：三块之间那条缝是**父窗口客户区**（子控件吞消息），拖拽走父窗口 + SetCapture，
  外观靠 WM_PAINT 自绘（不画就是灰底看不出能拖）。
- 「隐藏到托盘」要先确认托盘图标加上了再隐藏，否则进程叫不回来。
- `loadData()` 改成幂等：原本 main 和 GUI 各调一次，歌表翻倍成 1430，已下载扫描做两遍。
