## 更正：LIVE FINISH 确实存在（我 10-27 的判断错了）

10-27 我写"原作没有 LIVE FINISH"，那是**只翻了 sprite 表**（2807 条里确实没有 finish 字样）。
曲末特效是 **prefab 不是 sprite**，`stringliteral.json` 里这一族都在：

```
fx_result_finish          ← 血掉完、曲子结束时播的那个大字（用户确认）
fx_result_clear_v2        ← LIVE CLEAR（我们已实现的 LiveClearBanner 对应它）
fx_result_failed_v2
fx_result_full_combo_v2   ← 曲末 FULL COMBO 特效
fx_result_all_perfect_v2  ← 曲末 ALL PERFECT 特效
```

`badge_result_fullcombo` / `badge_result_allperfect`（358×76）是**结算页**的徽章，和上面
四支曲末特效是两回事 —— 用户在这一点上也是对的。

**现状**：曲末只做了 clear 那一支；finish / failed / FC / AP 四支都还没做。
要照抄它们的贴图与时间轴得用 AssetRipper 读 prefab YAML，而**这台机器只有 4GB 内存，
跑 GameData（672MB）会 OOM**（用户明确提醒过）。要做需换机器或改注入方式。

## 开屏动画（SEGA / Colorful Palette）也搬进来了

用户说"开屏动画所有资源没搬进来"，查下来**之前搜错地方**：

- 开屏不是 sprite，是 **`globalgamemanagers` 里的 Texture2D**，所以 `as_out`（sprite 名单）里
  永远查不到：
  `logo_sega`(766×256)、`logo_colorfulpalette`(1080×151)、
  `Splash Screen Unity Logo`(2048×1024)、`splash_attention`(1504×808)。
- 取法（几秒）：`AssetStudioModCLI <GameData>/assets/bin/Data/globalgamemanagers -m export -t tex2d -o ...`
  （866 个资产，853 张出来）。
- 另有 `globalgamemanagers` 里的场景名 `Assets/Sekai/Scenes/Splash.unity`：
  **开屏就是那个场景**，SEGA/CP 两张图挂在里面。
- 时序从 `dump.cs` 的 `TitleController`（:322615）读到：
  `SEGA_LOGO_DISPLAY_TIME=1`、`CP_LOGO_DISPLAY_TIME=2`、`ANIMATION_TIME=1`、`MIKU_CHARACTER_ID=21`。

实现：`TitleScreen` 现在分两段 —— 前 3s 是 `kSplashDur = kSegaDur(1) + kCpDur(2)`：
黑底 + SEGA/CP 交叉淡入淡出（各 0.15s 边），**不能跳过**（`splashDone()` 之前点按无效）；
之后才是标题（logo + TAP TO START + 版权），`t` 从 splash 结束算起。
`assets/title/` 现在 14 个文件（含 `splash_sega.png` / `splash_cp.png` / `splash_unity.png` / `splash_attention.png`）。

验证：`bash build.sh` → `build OK`；`CPSEKAI_TITLE=1 CPSEKAI_TITLE_T={0.5,2.0,4.5}` 三帧截图
`build/shots/boot_*.png`，SEGA 卡、CP 卡、标题页都对。
⚠ 构建前要 `taskkill /IM cppsekai.exe /F`，否则 lld-link 报 `Permission denied`。
