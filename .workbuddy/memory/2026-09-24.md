### 这次踩到的验证坑（值得记住）
- **`--sus` 单跑根本进不了 Play**：窗口一失焦 + `autoPauseOnBlur`（默认开）→ 前摇期间
  (`songTime < 0`) 直接退回选歌、停音乐。无头验证要在档案里写 `"autoPauseOnBlur": false`。
- **`--result-at` 不会记成绩**：那条门是 `songTime >= trackDurationSec - 0.25`（真实曲长），
  所以要用 `--bgm <短音频>` + `--filler 0` 跑完整局才能验经验结算；
  合成的短 wav 用 python `wave`，7 秒正弦就够（纯音没有静音头，filler 自然是 0）。
- 用户游戏/下载器开着时 `build.sh` 会 `Permission denied`：用 `OUT=build/probe.exe` 编，
  运行时要加 `--instance multi`（否则被单实例 mutex 挡掉）。
