## 设置卡片一批改动（用户一次提的 5 件事，全部落地 + 验证）

1. **账户页：导出 / 导入用户数据**
   - 原生 comdlg32 选择器（`GetSaveFileNameW` / `GetOpenFileNameW`），**build.sh 游戏链接行
     新加 `-lcomdlg32`**；`OFN_NOCHANGEDIR` 必须留（否则挑完目录 cwd 被改，`charts\` / 日志 /
     相对 `--sus` 全错）。
   - 导出 = `persistUserData()`（先刷活镜像）+ `game::saveUserData(挑的路径, ...)`，默认文件名
     `CppSekai-<昵称>-<yyyymmdd>.json`（非法文件名字符换 `_`）。
   - 导入 = 新加的 `game::isUserDataFile()` 先筛（**在弹确认框之前**）→ `ui::eulaDialog` 二次确认
     → `std::filesystem::copy_file` **覆盖 profile 文件本身**（不 re-serialize，保留未知键）
     → 重读 + `applyProfileLive()` + `++profileDataGeneration`。
   - 为此把 `activateProfile()` 里「重新推活镜像」那 55 行抽成 `applyProfileLive`（用
     `std::function` 前置声明，因为它在 activateProfile 下面才定义）。`CPSEKAI_IMPORTASK=1`
     可无头弹那张确认框。
2. **系统页：结束当前实例 / 结束所有实例**
   - 全部实例 = EnumWindows 找类名 `SDL_app` + 标题 `CppSekai` / `CppSekai - <user>` 的窗口，
     `PostMessageW(WM_CLOSE)`（不 kill）。main 里**新加 `SDL_WINDOWEVENT_CLOSE` 分支**
     置 `running = false`（以前只处理 SDL_QUIT）。二次确认 `killAllFrames`。
3. **判定页：判定预设 宽松 / 标准 / 严格（radio）**，出厂**宽松**（perfect 70 / great 120 /
   good 170 / bad 230 / miss 230 = 官方各 +30ms）；`UserSettings` / `JudgementWindows` 的默认值
   一起改成宽松。拖滑杆 → 选中态退成 -1。长条容错也从 pick-one stepper 换成 radio row。
   `game/Ui` 新增 `ui::radioRow`（圆点 + 标签，一行平分宽度，走焦点环 PadKStepper）。
4. **震动三勾 + 自动演出 挪到演奏页**（分别从判定、画面）。
5. **触摸屏滚页签**：SDL_FINGER* 攒竖直位移 → `##tabcontent` 里 `SetScrollY`；方向只判一次
   （12*scale 的 slop，|dy|>|dx| 才算翻页），hover 用 `AllowWhenBlockedByActiveItem`。
   `SDL_FINGERUP` **不清**累积量（快甩的 down/move/up 同帧到达，清了就整段丢）。
6. 顺手修：判定页工作副本原来只在「卡片刚打开那一帧」刷新 → 卡片开在演奏页时切到判定页永远
   不刷新；现在按「这一页第一帧」刷（`judgePageLastFrame`），导入后也自然重读。
7. 设置卡片 780 → **800** 高（演奏页加了两块，515/519 顶到边）；账户 488、演奏 515、
   判定 635（**故意滚动**）。
