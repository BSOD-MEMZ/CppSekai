
## chartdl MV 补下载被"已下载完整"拦住
- 根因：MV 下拉（kIdMv）**没有 CBN_SELCHANGE 处理**，`gMvChoice` 只在点「下载」时从 combo
  读一次 → 切换下拉后所有行的 done 判定仍是旧值，已下谱面的歌全部灰掉、勾不上，
  状态栏提示「这首歌已经下载完整了」。11-15 那次修复（songIsDone 加入 gMvChoice）
  只修了「按下下载时」这一半，UI 侧没接。
- 修：WM_COMMAND 加 kIdMv+CBN_SELCHANGE → 读 gMvChoice 后 rebuildList；rebuildList 的
  tick 恢复与状态列改走 songIsDone（状态列三态：已下载 / 缺 MV / 部分）；
  删除时一并删 mv/<id4>.usm 与 mv/<id4>_sekai.usm（残留 MV 会让下次下载误判已下），
  MV 计入 files.any；删掉未用的 mvY。
- 验证（无头）：build/testdl 造 0021 全套谱面+曲绘+sidecar（mv/ 空），
  `--screenshot` 拍「不含 MV」→ 灰文字/灰背景像素 99/7000；CB_SETCURSEL 3 + 手发
  WM_COMMAND(CBN_SELCHANGE) 后拍「两个都要」→ 0/0，状态列读作「缺 MV」。
  脚本套路：PostMessage 主窗口 WM_COMMAND(MAKEWPARAM(kIdMv,1), comboHwnd)。
