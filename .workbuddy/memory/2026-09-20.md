# 2026-09-20

## chartdl 数据源检查 + 国服曲下载修复

**用户报的两个症状**
1. 搜不到国服的「Hype Dive」
2. 下载国服歌曲只能拿到曲绘 + BGM，谱面一个都下不到

### 根因

**搜索**：`matchesFilter` 是裸字节比较 → `hype` 匹配不上 `Hype Dive`（必须照抄表里的大小写）。
顺带发现命令行参数的坑：GUI 子系统的 `argv` 是 **ANSI 代码页**解出来的，
`chartdl.exe --list 镜中少女` 到手就是乱码，中文/日文过滤在 CLI 上从来没生效过。

**谱面下不到**：`updateDetailPanel` 用 `available = level > 0` 判断"这首有没有这一档"，
而定数表 `music-levels.json` 停在 id 804（712 首），**17 首国服独占曲一行都没有** →
5 个难度框全灰 + 取消勾选 → 点下载只排到曲绘和 BGM。
用 09-20 打包版复现确认：五档全是 `easy （无）` + 按钮 `OFF`。

资源侧本身没问题（都实测过）：
- 谱面 `storage.sekai.best/sekai-cn-assets/music/music_score/11017_01/master.txt`（**带 .txt**）
- 音频 `.../music/long/vs_11017_01/vs_11017_01.mp3`（`se_` 前缀没有）
- 曲绘 `.../music/jacket/jacket_s_11017/jacket_s_11017.png`

- 新增 `foldCase()`：搜索查询 + 标题都折 ASCII 大小写，别名表加载也用它。

  面板里同一个 `kIdVocalBase + v` 的重复行用 `GetDlgItem` 守卫挡掉。

**`.workbuddy/tools/update_music_db.py`**

- 每个仓库补 **jsDelivr 镜像**（`cdn.jsdelivr.net/gh/...@main`）：2026-09-20 实测
  raw.githubusercontent 直接 000 超时，只留 raw 的话脚本跑不起来。

**数据**：`music-levels.json` 712 → 733 首（+21：241 / 290 / 809 敗走 / 811 ヘレディティ + 国服 17 首），

## 确定闪光全白 + 猜歌（13:20~13:40）

### 闪光（`main.cpp` 的 confirm flash）
- `kConfirmPeak` 0.88 → **1.0**：卡顿帧原来是"88% 白"，能透出列表 —— 用户说的"有点透"。
- 新增 `confirmWhiteShown`：**先画出全白的一帧，下一帧才 `startSession()`**。
  原来 `t >= kConfirmExpand` 就加载，而 cover 恰好那一刻才到 1，等于卡住时画的是
  "还没铺满"的上一帧。
- 失败路径不再硬切回列表，改成跳到淡出阶段。
- 验证：`--confirm-flash 1.0 --screenshot-time 1.35` → 逐像素全屏纯白，
  四角/中心全 (255,255,255)，1681 个采样点 min 通道 = 255。

### 猜歌（新功能）
- 选曲界面头排「音乐商店」右边新增按钮（`assets/select/guess.png`，
  `guessX = storeX + storeW + 10k`；多人横幅右边界同步改 `guessX + guessW`）。
- 点开是 `ui::beginCard` 卡片（复用个人资料/messageDialog 那套）：一个大号粉色别名
  + 2x2 四个曲名胶囊，答完锁死并染色（薄荷=正确、红=选错），下面统计 + 下一题/关闭。
- 题库 = 社区别名表里**唯一且有意义**的条目（12660/12896 可用）：单一答案、≥2 字节、
  非纯数字、不等于曲名/读音、且没有别的歌叫这个名。池子缓存在 `gGuessPool`。
- 干扰项随机别的曲名，四项互不相同。出题打 `[guess] "别名" -> id 曲名 | *正确 / 干扰...`。
- `--guess` 调试钩子（同 `--profile`）用于 `--screenshot`；CLI.md 已补。
- 选项胶囊不能用 `ui::capsuleButton`（只有薄荷/白两色）→ 自己写 `guessOptionPill()`，
  外观照抄它（半高圆角+底部阴影+bodyFont 居中），填充色由状态给。
- 新工具 `.workbuddy/tools/ascii_view.py`：把 PNG 按格子平均成 ASCII，用来在没有看图能力时
  粗看版式（亮/暗/粉/薄荷/红/白各有字符）。诊断用，不做断言。
