## 四项改动（全部完成并编译验证）
1. **charts 找不到**：exe 按目录解析 charts，build/ 下没有 → main.cpp 现在依次尝试
   `--charts` / `build\charts` / `build\..\charts` / `./charts`，取第一个非空的；为空时打印全部尝试路径。
2. **音乐对不上**：根因是官服 mp3 开头有静音填充（musics.json 的 `fillerSec`=9.0，实测 0075/0127 均为 ~8.95s），
   谱面 tick0 在静音之后。AudioEngine 重写时钟：`音乐文件位置 = songTime + startPos + userOffset`；
   新增 `detectLeadingSilence()`（ma_decoder 扫描前 20s，阈值 -45dBFS，<0.3s 视为无填充）。
   优先级：sidecar json `fillerSec`/`offset(ms)` > 自动静音检测 > 0；`--filler` 可覆盖，`--offset` 手调。
   getChartEndTimeSec() 已从核心导出（core_api）。
3. **字体跟随系统**：Intro.cpp 新增 systemFontCandidates()：SPI_GETNONCLIENTMETRICS 拿 UI 字体名 →
   注册表 Fonts 键模糊匹配（键名是 "A & B (TrueType)" 形式，需按 & 拆分 + 前缀匹配）→ 候选回退列表。
   加载后用 GetFontBaked 探测 CJK 字形（初ミ詞设），失败换下一个。本机结果：Yu Gothic UI 是 CFF 轮廓
   stb_truetype 无法渲染 → 探测失败 → 自动落到 Microsoft YaHei UI (msyh.ttc)。`--pjsk-font` 可用回 bundled 字体。
4. **SMTC + 任务栏进度条**：新文件 platform/SystemMedia.{hpp,cpp}。工具链无 Windows SDK，
   WinRT ABI（ISMTC/DisplayUpdater/MusicProperties/TimelineProperties/IPropertyValueStatics）手写 vtable，
   IID 与方法顺序用自写的 winmd 解析脚本从 C:/Windows/System32/WinMetadata/Windows.Media.winmd 读出
   （脚本保留在 .workbuddy/tools/）。RoGetActivationFactory 等通过 LoadLibraryW("combase.dll") 动态加载，
   无需导入库。ITaskbarList3 也是手写 vtable（slot3=HrInit, 9=SetProgressValue, 10=SetProgressState）。
   SMTC 需要 interop：RoGetActivationFactory("Windows.Media.SystemMediaTransportControls",
   IID_ISystemMediaTransportControlsInterop).GetForWindow(hwnd, ...)。
