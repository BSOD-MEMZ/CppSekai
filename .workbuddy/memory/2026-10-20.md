## 教学：用户名卡片 + 教学 BGM（已提交 28d62f3）

照用户给的 pjsk 截图做了 `type: "name"` 步骤，插在「你叫什么名字？」后面（下标 3，
后面所有步骤 +1）。

- `storyui::nameCard`：淡紫整块底板 + 说明行 + 圆角输入框（右端自绘铅笔）+ 粉色
  「*之后也可更改。」+ 薄荷「确定」。底/字/粉/薄荷全走 `ui::kCardBg/kRowsBg/kNotePink/kPrimary`。
- **卡片必须画在窗口 draw list**（不是前景层）：输入框文字是 ImGui item，画前景会把字
  盖住。压暗也一起画在那儿，所以 Story.cpp 里 dim 对 name 步跳过。
- 限长按 UTF-8 **码点**（InputText callback + DeleteChars），按字节会把 10 个汉字砍成 3 个。
  实测：档案名 15 个字母 → 卡片里只有 10 个。
- **focus-by-code 会全选文本**，而全选是**下一帧**才出现 → 用一个静态 `ImGuiID` 记住
  「还欠一次清选中」，看到 `HasSelection()` 就 `ClearSelection()`（caret 留在末尾）。
  用 callback 里改 SelectionStart 不管用（会被 clamp 成 0）。
- 确定 → `Host::commitName` 写 account.name + profiles/index.json 的 label + 房间名 +
  窗口标题 + persistUserData。空输入按 hint（「世界」的居民）兜底。
- name 步要额外挡三处：advance（点哪都推进）、对话框、顶栏命中孔（模态）。手柄 A 走
  `gNamePadConfirm`。
- BGM：`platform::AudioEngine::startTutorialBgm/stopTutorialBgm`（独立 streaming 循环
  声部，别复用 result BGM 的槽）；main 在 `story::draw` 之前按
  `story::active() && !story::suspended()` 每帧调，选曲预览那段多一个 `!tutorialAudio`。
  进演奏/结算自动停，回选曲再起。

## 验证踩的坑

- **残留实例**：`--player` 起的那个进程没退，新实例变成 member，用的是空档案（等级 1、
  EULA 又弹出来）—— 一度以为是档案被改了。先 `tasklist | grep cppsekai` 清干净再看。
- `--story-test` 的循环：结束那一帧 `testing` 恒真 → 立刻又 start 一遍，所以
  「tutorial bgm stopped」只在**非** test 模式看得到（要临时把 tutorialDone 改 false）。
- 截图前要 `eulaAccepted` 为 true（本机 default 档案是 false），临时改 → 截 → 立刻还原，
  别忘了 `profiles/index.json` 里的 name 也可能被 syncProfileLabel 改写。
- 无头按键打不进 ImGui（PostMessage WM_CHAR 不产生 SDL_TEXTINPUT），打字只能靠人手动试；
  鼠标点击用 `.workbuddy/tools/click_at.py`（真实光标 + SetCursorPos）**有效**，
  坐标是客户区像素，注意按 `1120/1920 = 0.583` 缩放。
