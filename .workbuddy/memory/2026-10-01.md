### 给 main.cpp 加了确定性序列捕获（本次唯一代码改动，+368 行）

新增 5 个参数，只在捕获时生效，不写 `userdata.json`：

| 参数 | 作用 |
|---|---|
| `--capture <dir>` | 每帧原始 RGBA（bottom-up，不翻转）写 `<dir>/frames.rgba` |
| `--capture-fps` | 默认 60 |
| `--capture-start` / `--capture-end` | 按**虚拟时钟**截区间 |
| `--script <file>` | 按虚拟时间注入输入 |

脚本语法：`move` / `glide` / `click` / `dbl` / `down` / `up` / `wheel` / `key` / `keydown` / `keyup`。

**核心设计：捕获时墙钟被换成虚拟时钟。** `wallSongTime()`、`songClock()`、
`resolveSongClock()` 读 `captureClockSec`（每帧 += 1/fps），`ImGui::GetIO().DeltaTime`
也强制成同一步长（所有 `ui::anim`、卡片入场、悬停生长都吃它），并且**不启动音频设备**
（否则音频时钟会把谱面时间拽回实时）。所以是逐帧精确、可复现的 60fps，不丢帧不抖动。
实测 1920x1080 每帧 ~31ms（约 2 倍实时），180 帧 = 3.0s 精确。

**踩到的两个坑（都很隐蔽，记下来）：**

1. **注入事件的 `windowID` 必须填真实窗口 ID。** `ImGui_ImplSDL2_ProcessEvent` 会给每个
   鼠标/滚轮事件做 `ImGui_ImplSDL2_GetViewportForWindowID(event->windowID)`，查不到就
   **丢弃**。填 0 的结果是"注入静默失效"——画面一帧都不变，日志也全正常。
2. **注入鼠标坐标时要同步 `SDL_WarpMouseInWindow`。** ImGui 后端在「窗口有键盘焦点但
   没有鼠标焦点」时会 fallback 到 `SDL_GetGlobalMouseState()`，把注入的坐标覆盖掉。
   把真实指针挪到脚本指定的位置，两条路径就一致了。

顺带修的：`--screenshot` 的日志重定向条件、退出时 `persistUserData()` 的守卫都要带上
`captureDir`。`build.sh` 全量编译 0 warning。

### 素材/分析结论

- `se_0374_01.mp3`：121.64s，**前 9s 是静音填充**（sidecar `fillerSec: 9.0`），180 BPM
  （谱面 `#BPM01: 180`），所以要 4 拍（1.333s）一格排切点。
- 段落（音乐文件时间 M）：9–25 弱起 / 25–46 推进 / 46–66.5 副歌1 / 66.5–75 间奏 /
  **75–101.5 终副歌（最响）** / 101.5–118 尾奏。视频时间 V 与 M 的关系：**M = V + 8.6**。
- 完整版 MP3（265s）与 game size 版**不是简单裁剪**，包络互相关找不到干净偏移
  （最短归一化距离 1.11 ≈ 噪声），说明 game size 是重新编排的裁剪版 —— 所以"直接对齐"
  这条路本来就不通，他改口径是对的。
- 谱面 0374 = チームメイト，与 BGM 天然对拍。chart 0 = 音乐时间 9.0s。

### 后期管线的两个约束（实测）

- 这个 ffmpeg 构建**没有 `-filter_script`**，只能用 `-vf` 单引号传滤镜。
- `fontfile=` 里的 `C:` 冒号会把滤镜解析器带崩（`No option name near '/Windows/...'`）。
  解法：把字体复制到本地用**相对无冒号路径**（`fonts/msyhbd.ttc`）。中/日文都能正常渲染。
