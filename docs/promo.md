# CppSekai 宣传用语备选

> 侧重：**用学校希沃 + 和同学一起玩**。2026-09-24 整理。
> 挑的时候注意：主 slogan 只留一条，其余当备选；同一条别在标题和封面里各用一遍。

---

## 一、主 slogan 候选（只选一条当门面）

| 候选 | 味道 |
|---|---|
| **上课是教具，下课是街机。** | 对仗 + 反差，最百搭，适合放在封面/标题/简介首行 |
| **希沃不是用来放 PPT 的。** | 最冲、最有梗，态度最像你本人 |
| **课间十分钟，讲台变街机厅。** | 画面感最强，把「十分钟」这个稀缺资源点出来了 |
| **全校最贵的那台电脑，现在要排队。** | 反讽，夸机器不夸自己 |
| **没有 Electron，没有引擎，双击就开打。** | 技术向，圈内人喜欢，圈外人无感 |

**我会推第一条**：它把「上课/下课」和「教具/街机」两个对立面塞进 10 个字，谁都能秒懂，也不挑平台。

---

## 二、备选 slogan（按角度分组，可混搭）

**场景 / 场面**
- 一个班，一台希沃，一条队。
- 手一伸，全班都安静了。
- 不用手柄，不用手机——伸手就是判定线。
- 课间铃一响，讲台前就开始堵人。
- 十分钟，一首歌，一整个班。

**反叛 / 反差**
- 上课它是教具，下课它是街机。
- 讲台归老师，课间归我们。
- 它这辈子放过最多的 PPT，不如课间这一首歌。
- 希沃的第二职业。

**电教委员身份**（这条线你独有，别人抄不走）
- 电教委员的最高权限。
- 报修一次，装一个。
- 六年电教委员，就为了这几天课间。
- 全班只有我知道希沃的密码。

**务实 / 技术向**
- 一个 exe，一张 U 盘，哪台希沃都能跑。
- 10MB，不装环境，不联网，拷过去就打。
- 零安装，零依赖，插上就跑。

## 四、视频简介

### 短版（直接贴）

```
一个 exe，拷进 U 盘，插到教室的希沃上，双击。

课间十分钟，够打一首歌。

没有 Electron，没有引擎，没有安装包——全校最贵的那台电脑，
现在是我们班的街机厅。
```

### 长版（专栏 / 视频简介展开）

```
上课铃一响，它是教具；课间铃一响，它是街机。

学校那台希沃平时只用来放 PPT，触摸屏大半时间闲着。我做了个
Windows 原生的小音游，一个 exe、10MB、不用安装、不用联网，
拷进 U 盘插到希沃上就能玩。

课间十分钟够打一首歌。同学不用学操作，手伸上去就能打——
判定线就在屏幕上，摸就是了。

没有 Electron，没有引擎，没有"先装个运行库"。
双击，开打，上课前关掉。

班里最贵的两块玻璃，终于有了它该有的用处。
```

## 五、封面大字（4-6 字，要够大）

- 课间十分钟
- 希沃的正确用法
- 讲台变街机
- 全班排队打烤
- 不用装，双击就玩

建议：**大屏/希沃机身占画面 + 6 个大字**。字少、字大、能一眼读懂，比堆小字强得多。

## 六、置顶评论

```
没有 Electron，没有引擎，双击就能跑。

教室那台希沃是 Windows 的，插 U 盘就能用，不用装任何东西。
课间十分钟够打一首歌，同学上手不用教。

（有同款希沃的同学，评论区说下你们班那台是什么配置）
```

最后那句是**留话题**用的——有人回复就会把评论区顶起来。

## 十、一条取舍建议

「希沃 + 同学 + 课间」这个角度**不需要提游戏名字**也是完整的，甚至更强：
它讲的是"教室那台大屏"和"十分钟"这两个所有学生都有的共同经验，不是某个游戏的粉丝向内容。
真提名字的时候再提，标题和封面优先留白。
